# 🛒 Marketplace Digibuybr - Levantamento de Requisitos

## 📖 Sobre o projeto
Este repositório foi desenvolvido como parte da **2ª Avaliação de Acompanhamento – 1º Semestre** da disciplina **Business Systems Planning, Analysis & Design**, ministrada pelo professor Renato Jardim Parducci.

O objetivo do trabalho é realizar o **levantamento de requisitos** para uma plataforma de marketplace digital fictícia chamada **Digibuybr**, incluindo análise de requisitos funcionais e não funcionais, pesquisa de sistemas existentes e aplicação de brainstorming e design thinking.

## 🎯 Objetivo
Documentar e estruturar os requisitos de um sistema de marketplace digital, visando:
- Cadastro de anunciantes e compradores
- Gerenciamento de produtos e preços
- Controle de pagamentos
- Planejamento logístico das operações
- Melhoria da experiência do usuário
